Firebase setup needed

This app needs a Firebase project before it can run. In index.html, find the firebaseConfig object near the bottom of the file and replace the placeholder values with your own project's config.

  1. Create a project at console.firebase.google.com.
  2. Add a Web App to the project and copy the generated config object.
  3. Enable Firestore Database (production mode).
  4. Enable Authentication → Sign-in method → Email/Password.
  5. In Authentication → Users, manually add an account for each coach/manager who needs access — there is no public sign-up.
  6. Publish the Firestore rules from firestore.rules in this repo (Firestore → Rules tab).

See README.md in this repo for the full walkthrough.
